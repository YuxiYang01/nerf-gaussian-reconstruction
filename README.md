# NeRF & Gaussian Splatting Reconstruction

This project explores novel view synthesis using:
- NeRF (Nerfacto)
- 3D Gaussian Splatting (Splatfacto)

Pipeline:
1. Data capture
2. COLMAP reconstruction
3. NeRF training
4. Gaussian Splatting training
5. Evaluation & analysis
